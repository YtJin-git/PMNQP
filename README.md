# PMNQP
Primitive Memory Networks with Qualified Prompts for Compositional Zero-Shot Learning

**Published in IEEE Transactions on Image Processing (TIP), 2026 (Early Access).**

Yutang Jin, Boyu Zhao, Shitao Chen, Shiming Chen, Guo-Sen Xie, Yisong Wang, and Xinge You

[Paper](https://ieeexplore.ieee.org/document/11773295) | [DOI](https://doi.org/10.1109/TIP.2026.3748354)

## Overview

PMNQP combines qualified textual prompts with primitive visual memories for compositional zero-shot learning. The prompts use descriptions generated offline by an LLM, while attribute and object memory banks provide complementary visual evidence. No LLM access is required during training or inference.
